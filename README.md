# AutomAI Booking Demo

Demo conceptual de un sistema web de reservas + CRM para negocios de servicios, presentada con una barbería ficticia como caso de uso.

## Incluye

- Sitio público responsive.
- Servicios y profesionales.
- Flujo de reserva en 4 pasos.
- Disponibilidad simulada y bloqueo de horarios.
- Persistencia local con `localStorage`.
- Vista negocio / CRM.
- Agenda, clientes, métricas y servicios.
- Sincronización visual de nuevas reservas hacia el CRM.

## Stack de esta demo

- HTML5
- CSS3
- JavaScript vanilla
- LocalStorage
- Google Fonts

> Esta versión es un prototipo frontend para portafolio. La versión de producción propuesta evolucionaría a Next.js + TypeScript + Supabase/PostgreSQL + Auth/RLS + automatizaciones, WhatsApp y pagos según el cliente.
